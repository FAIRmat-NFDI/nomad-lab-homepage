Developer Overview

lock_open NOMAD is open source

NOMAD’s core platform is open source under the permissive Apache 2.0 license. The plugins developed through FAIRmat are open source as well, and community contributions—from focused fixes to new domain support—are welcome across the ecosystem.

Development paths

Extend NOMAD—or work on the platform itself

Use plugins to add domain- or institute-specific functionality. Choose core development when you need to work directly on NOMAD’s backend services, data model, processing, search, or supporting infrastructure.

Recommended route
extension

Develop a NOMAD plugin

The recommended route for adding institute- or domain-specific functionality without changing the core platform.

  • check Add parsers, schema packages, normalizers, apps, dashboards, APIs, actions, or NORTH tools
  • check Develop, test, document, and publish a reusable Python package
  • check Improve an existing FAIRmat plugin and contribute the change upstream

Core platform
code

Contribute to the core software

Choose this route when a change belongs in NOMAD’s shared framework, backend services, infrastructure, or documentation.

  • check Set up the Python environment and supporting services
  • check Navigate the data model, processing, search, APIs, and infrastructure code
  • check Create a branch, run the relevant tests, and prepare the change for review
  • Set up core development →
  • Navigate the code →
  • Contribution workflow →
forum

Planning a core contribution?

Core changes are less common than plugin development. We suggest contacting the NOMAD maintainers early to discuss the scope and contribution route.

Start developing a plugin

Begin with a maintained starting point

Plugins are the primary way for data stewards and infrastructure developers to adapt NOMAD for an institute, scientific domain, or data workflow.

Instrument development

Extending instrument control with CAMELS?

NOMAD CAMELS has a separate development workflow for creating and sharing instrument drivers or contributing to the measurement software itself. Its contribution guide is the primary starting point for this workflow.
