How to read this list

The main file is the file NOMAD uses to recognize a calculation. Some parsers also read input, structure, trajectory, or analysis files in the same folder. Method and workflow support is shown only when a parser's mapping report explicitly maps the corresponding NOMAD schema section. “None” means that the available report contains no mapped high-level method or workflow; “Unknown” means no mapping report is available. Likewise, “Not documented yet” does not necessarily mean that no other files are read.
