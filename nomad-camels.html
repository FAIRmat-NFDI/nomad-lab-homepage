Open source · FAIR data

Control instruments, run protocols,
record FAIR data.

NOMAD CAMELS turns research ideas into configurable measurement and process protocols. Build and run common protocols without writing orchestration code, connect laboratory instruments, and capture data with rich metadata.
Features
What NOMAD CAMELS gives you
NOMAD CAMELS is an open-source desktop application for designing and running measurement protocols, controlling instruments, and capturing experimental data with rich metadata.
account_tree
Visual protocol builder

Assemble measurement and process protocols through the graphical interface. CAMELS generates the underlying Python and Bluesky code.

settings_input_component
Instrument drivers

Install community-developed drivers, use local drivers, or create support for additional instruments with the built-in driver tools.

show_chart
Live measurement & visualization

Run measurements, monitor their progress, and visualize incoming data in real time.

inventory
Structured data capture

Store measurement data together with timestamps, protocol information, instrument settings, and other experimental metadata.

cloud_upload
NOMAD integration

Connect CAMELS to NOMAD Central or a NOMAD Oasis to use sample information and transfer measurement data directly into NOMAD.

hub
Local & distributed control

Control directly connected laboratory instruments or communicate with larger distributed systems through EPICS.

Benefits
Why use NOMAD CAMELS?
Reduce the effort required to automate changing experimental setups while retaining control over how measurements run and how their context is recorded.
speed
Automate experiments faster

Build, reuse, and adapt measurement protocols without writing orchestration code for every experiment.

tune
Adapt as setups change

Add or exchange instruments and modify protocols as experimental requirements evolve, from small laboratory setups to distributed control systems.

share
Make data reusable from the start

Capture experimental context during acquisition so results remain understandable, reproducible, and ready for integration with NOMAD.

Who builds it
Developed at FAU through FAIRmat

NOMAD CAMELS is developed at Friedrich-Alexander-Universität Erlangen-Nürnberg within the FAIRmat consortium, combining laboratory automation expertise with FAIR research-data practices.
