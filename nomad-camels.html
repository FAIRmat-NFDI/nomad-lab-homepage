NOMAD CAMELS lets you turn research ideas into measurement and process protocols in minutes. Implement instrument communication without programming skills, increase productivity and flexibility, and produce FAIR data.
Features
What is NOMAD CAMELS?
NOMAD CAMELS is a standalone open-source measurement software targeted towards the requirements of experimental physics. Ease of use, rich metadata, and FAIR-compliant data are at the heart of CAMELS design. It is suited for any researcher wanting full control and full documentation of experiments without the need of programming skills.
download
Smooth installation

CAMELS is a Python package distributed via PyPI. It installs easily on any computer, and on Windows the installer does all the work for you.

check
Easy to use

No programming skills required. Configure your measurement and process protocols, and get it done within minutes.

book
FAIR data

Automatically store FAIR data with rich metadata so you and others can understand your experiment in detail. Optionally connect directly to your NOMAD Oasis.

tune
Flexible and extendable

Add further instruments to your setup at will. Reuse and adapt existing measurements quickly.

hub
Scalable

Work with small setups using directly connected instruments, or connect to large distributed systems using advanced protocols like EPICS.

group
Community driven

Contribute to CAMELS and add new instruments on GitHub. CAMELS comes with an instrument driver wizard that helps you implement new instruments.

How to run NOMAD CAMELS
CAMELS is distributed via PyPI and can run on any computer that supports Python. There is a special installer for Windows. See our installation guide in the documentation.
01
CAMELS software

CAMELS requires a desktop computer running Windows, Linux/UNIX, or macOS. The required Python environment is installed either through the installer on Windows or manually via the installation guide.

02
Drivers

Once installed, CAMELS lets you install instrument drivers from PyPI via the graphical user interface. You can also create and run local self-developed instrument drivers.
