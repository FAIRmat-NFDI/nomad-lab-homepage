Benefits
Why NOMAD is different
NOMAD is not about sharing files, it is about sharing data and making data FAIR. All data is organized in well-defined structures described by a formal schema. That shared schema enables consistent search, APIs, interoperability, and analysis across data from diverse sources.

Structured data & Metainfo

All data in NOMAD follows a schema that defines how data is hierarchically structured and cross-referenced. This schema is called the NOMAD Metainfo. It covers general domain-independent structures and detailed, method-specific content.

  • NOMAD parsers automatically structure your data
  • You can extend the existing NOMAD schema
  • All data is hierarchically organized and connected
Understand NOMAD's data structure →

Analysis tools (NORTH)

Because all data is uniformly organized, you can analyze data from different sources with the same tools. The NOMAD Remote Tools Hub (NORTH) runs Jupyter and other containerized applications directly alongside your data.

  • Use JupyterLab for notebook-based analysis
  • Process microscopy images with FIJI
  • Visualize atomistic structures with VESTA

NOMAD Central Test

Test workflows safely

A separate NOMAD Central deployment and database for practicing uploads, publication, and other workflows.

  • Test publication and other day-to-day workflows
